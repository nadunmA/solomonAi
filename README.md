# ⚡ Solomon AI — AI Image Prompt Library

> **Stop typing from scratch.** Browse tested prompts, copy with one click, and generate stunning visuals across ChatGPT, Microsoft Copilot, Google Gemini, and Grok.

🌐 **Live Demo:** [solomonprompts.space](https://solomonprompts.space/)

---

## ✨ Features

- 🎨 **Curated Prompt Gallery**: Hundreds of pre-tested, high-fidelity image prompts paired with visual showcase previews.
- ⚡ **One-Click Copy & Quick Launch**: Instantly copy prompts to your clipboard and jump directly into your AI engine of choice (ChatGPT, Gemini, Copilot, Grok).
- 🎲 **Random Prompt Discovery**: Explore random inspiration with the built-in shuffle and discovery view.
- 🌌 **Cyberpunk & Glassmorphic UI**: High-tech aesthetic featuring animated terminal prompt decoders, scanlines, and glowing ambient accents.
- 📱 **Fully Responsive**: Optimized for ultra-fast browsing on desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 7](https://vitejs.dev/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment**: [GitHub Pages](https://pages.github.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/solomonAi.git
   cd solomonAi
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
